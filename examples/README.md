# Examples

The `.bin` files are 16-bit Thumb programs captured from trainers. Matching
`.lst` files are human-readable output from `build/tools/disasmthumb` and are
kept beside the binaries so they can be reviewed or printed without rebuilding
the host utility.

`student-projects/` contains the three save slots captured for each classroom
project. A listing is generally included for the first slot, which was the slot
used for printing and review.
